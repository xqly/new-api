# Site redesign

## Scope

All frontend routes share a Notion-inspired foundation. Homepage: Persuade. Authenticated tools and forms: Operate. Supporting content: Read.

## Direction contract

THESIS: One gateway, presented with the clarity of a document workspace.

OWN-WORLD: User-pinned reference, https://www.notion.com; white ground, Inter typography, black text, blue actions, warm gray navigation and quiet pastel accents. New API branding and product truth remain intact.

STORY: Read the gateway proposition, inspect the labeled interactive workspace, recognize compatible providers, understand capabilities, follow the existing configuration flow.

FIRST VIEWPORT: A standard navigation strip, two balanced lines of large centered type, a compact action group, then the gateway workspace preview. No gradient backdrop or floating glass header. On mobile the preview becomes a document without an ornamental sidebar.

FORM: Code-led implementation of the user's explicit reference; no alternate visual directions. The signature interaction is a real keyboard-accessible switch between channel and API views in the preview. Operational navigation, tables and settings inherit the same semantic tokens and compact geometry.

## Constraints

Existing backend, authorization and data contracts stay in place. Synthetic preview values are labeled. Administratively configured content keeps its behavior. No deployment is required to inspect the build and captures.
